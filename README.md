
# Isothermal Work Calculator

A simple web-based calculator for calculating the work done by an ideal gas during an isothermal process.

## Formula

\[
W = nRT \ln\left(\frac{V_2}{V_1}\right)
\]

Where:
- `W`: Work done by the gas (J)
- `n`: Number of moles (mol)
- `R`: Ideal gas constant (8.314462618 J/mol·K)
- `T`: Absolute temperature (K)
- `V1`: Initial volume (m³)
- `V2`: Final volume (m³)

## Features

- Calculates work for isothermal expansion and compression
- Displays the work in joules and kilojoules
- Shows the volume ratio, natural logarithm, and `nRT`
- Responsive dark-themed interface
- Runs directly in the browser without a backend

## Technologies

- HTML
- CSS
- JavaScript

## Usage

1. Enter the number of moles and temperature.
2. Enter the initial and final volumes.
3. Click **Calculate Work** to view the results.

The calculator assumes an ideal gas and a constant temperature.
